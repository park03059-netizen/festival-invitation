- 이름 넣은 초청장: 주소 뒤에 `?to=홍길동`
- 운영진 화면: https://park03059-netizen.github.io/festival-invitation/admin.html

## 어떤 파일을 고치나요?

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| 축제 이름·날짜·주소·일정·아티스트·교통 안내·사진첩 | `config.js` |
| 공지 문구·응답 마감일·아티스트 공개일 | 운영진 화면 (또는 `config.js`) |
| 카톡 미리보기 제목·그림 | `index.html` 윗부분, `images/og-image.png` |
| 사진 추가 | `images` 폴더에 넣고 `config.js`에 파일 이름 적기 + `CREDITS.md`에 출처 적기 |
| 직접 해야 하는 설정 | `설정안내.md` |
